The manifest

~/models/modelbar.json — the single source of truth. Adding a model here is enough to make it loadable, selectable in every harness it can drive, and accounted for in the memory budget.

backends[]
id
Stable key. Models reference it; harness provider keys default to it.
port
Where the real server listens. For a proxied backend this is internal and never given to clients.
publicPort
Present ⇒ on-demand. ModelBar binds this one and owns the process lifecycle behind it.
managed
false marks a service ModelBar must never stop (Ollama is a launchd job).
apis
Wire formats actually served: chat, responses, messages. This gates harness eligibility.
telemetry.kind
Which parser reads live stats: ds4 · llamacpp · ollama · comfyui · localai · none.
process
any matches the program identity (exec path + argv[0]) — not the whole command line.
memoryAccounting
nominal (default) charges the declared size; measured charges real footprint.
models[]
servedName
Must match what the backend reports as loaded. A mismatch shows the model as “not loaded” while it is plainly running.
estimatedGB
Declared resident size. Drives the budget guard and the memory attribution.
requires[]
Files that must exist. Missing ⇒ the row is greyed with the filename, and it cannot be selected in a harness.
start.argv
Exact launch command, argv array — never a shell string, so nothing can be re-split or injected.
context
flag + options[] + defaultSize. Restart-to-apply; the picker prices each rung against the budget.
harness.apiName
The string a client puts in the request body's model field. Often not the id and not servedName.
sleepIdleSeconds
Idle timeout before a proxied backend is stopped. Only meaningful with a publicPort.
metadataPath
Explicit config.json / .gguf for reading the trained context ceiling and KV cost, when requires doesn't name one.
Validation catches these
! duplicate backend / model id
! model references unknown backend
! port claimed by two backends
! publicPort equal to port — the proxy would forward to itself
! out-of-range port · empty start.argv · missing required file
$ ModelBar --cli validate
The manifest is not hot-reloaded

Editing the file has no effect on the running app until it is fully quit and relaunched. And quitting stops every backend a proxy is holding — so a manifest edit can restart a model somebody is mid-conversation with. Check what is loaded first.
