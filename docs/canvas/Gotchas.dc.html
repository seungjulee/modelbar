Things that will bite you

Each of these cost real debugging time. They share a shape: something silently disagrees with what the config says.

A saved context size outranks the manifest
Your last pick is persisted in UserDefaults and silently overrides context.defaultSize. Change the manifest to 64K, and the server can still launch at 128K — the value that overran the GPU cap. Set it explicitly with --cli context, and check ps for the real -c.
servedName mismatches fail quietly
If it doesn't match what the backend reports, the model runs fine and shows as not loaded. Backends change this out from under you: swapping mlx_lm.server for mlx-dspark changed the reported id from a full descriptive name to 8-bit.
Speculative decoding is not free
A drafter can cost more than it saves. On this machine DSpark measured 43.2 t/s against 44.9 without, plus 10% slower prefill and 4× the first-token latency — on a correctly checkpoint-matched drafter. Always benchmark both ways on your own prompts before wiring one in.
ds4 must run from its own repo root
Metal shader sources resolve relative to the working directory. Launch it from anywhere else and it dies with metal backend unavailable — which reads like a driver problem and isn't. Use start.cwd.
Stray clients hold backends open
A forgotten agent session in another terminal keeps a connection alive, blocks the idle reaper, and quietly contends for the shared backend — showing up as a mysterious stall or a halved benchmark. Check lsof -i tcp:<port> before believing a slow number.
Power state changes the numbers by 2×
On battery, or with Low Power Mode on, GPU throughput roughly halves — the same config measured 44 t/s on mains and 20 t/s unplugged. Check pmset -g batt and pmset -g | grep powermode before recording any result.
Shared log files hide the real error
Models on one backend share a logPath, and failure reporting reads from a byte offset. A start that dies instantly — couldn't bind HTTP server socket, say — can surface as a bare “Server exited during startup”. Run the argv by hand to see what actually happened.
