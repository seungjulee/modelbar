Memory

The most misread part of running big local models. Every per-process tool lies here, and they lie in different directions.

Why RSS is useless for this

These servers mmap their weights, so the pages live in the shared file cache rather than any process's private footprint. ds4-server reports roughly 20 MB RSS while holding an 84 GB model. A process list will tell you nothing is using memory while the machine is full.

Where a model's weights actually live
Wired
Once the GPU holds them. Pinned so Metal can address them directly — not reclaimable, and invisible to per-process tools.
Cached (file-backed)
While merely mmapped. Reclaimable on demand — and excluded from Activity Monitor's “Memory Used”.
The trap this creates

“Memory Used” is app + wired + compressed and excludes the cache. So a 92 GB model that is mmapped but not yet GPU-resident makes the RAM bar read 29% while only 0.6 GB is actually free. Charging a declared model size against “used” alone yields a negative remainder.

ModelBar's attribution line therefore measures against used + cached, which covers both homes and stays consistent as pages migrate between them.

The denominator is stated inline because it deliberately differs from the bar above it. Sizes are the manifest's declared figures — an attribution, not an audit.

The budget guard

Loads are checked against settings.memoryBudgetGB using each model's declared estimatedGB, never measured RSS — measuring would under-count wildly and approve loads that cannot fit. A manual load over budget asks first; an auto-start from a proxied request proceeds and leaves a note, because nobody is watching the screen to answer a dialog.

Backends that allocate anonymously and idle cheap (ComfyUI) are marked memoryAccounting: measured instead, so merely being reachable doesn't charge their full pipeline size.

Swap: only growth matters

macOS never pages swap back in just because pressure dropped, so a non-zero figure is routinely hours stale. ModelBar flags it red only when it is growing over a 60-second window, past a 256 MB dead-band.
