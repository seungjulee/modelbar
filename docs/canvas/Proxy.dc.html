The proxy

A TCP-level splice, not an HTTP proxy. Working at the byte level means streaming (SSE), chunked encoding and keep-alive all just work, because none of it is interpreted.

What happens on a connection
1
Probe the internal port (0.6 s). If the backend answers, splice the two sockets and copy bytes until either side closes. Warm traffic never gets inspected — this path is untouched.
2
Cold: read the first request line. A bare TCP connect is not a reason to load 84 GB. Only requests that genuinely need weights wake anything.
3
Spawn and await health, holding the client open. Then splice, replaying the bytes already read so the backend sees the request exactly as sent.

This exists because harnesses enumerate their providers at startup. Launching Hermes touched the ds4 port and silently loaded DeepSeek — even with a different model selected.

Idle reaping

A backend is stopped after its sleepIdleSeconds with no live connections. The gate is the open-connection count, not a timestamp — a long generation with one attached client is never reaped mid-answer. On quit, every proxy stops the backend it started, including one caught mid-launch.
