ModelBar

A menubar manager for local LLM backends on Apple Silicon. It owns the ports your clients already point at, so a model starts on the first real request and stops when nothing is using it.

The one idea

An 84 GB model takes ~30 s to load and holds memory until something kills it. Rather than leaving it resident, ModelBar binds the public port itself and keeps the client's connection open through the cold start. From the client's side that looks like one slow first response — which is the whole trick.

What the menu shows
Memory
RAM, GPU wired cap, swap trend — plus an attribution line naming which model the memory belongs to.
Models
Every manifest entry with its backend, size and load state. Click to load; hover for Restart, Stop and the context picker.
Backends & Processes
Port health, served model, live telemetry; and the real processes with footprint, CPU and uptime.
Harnesses
Point Hermes, Pi, Codex or Claude Code at any eligible model. Selecting one writes that harness's config — nothing else touches those files.
Status colours mean one thing everywhere
up · under 70% · healthy
70–90% · getting tight
90%+ · about to hurt
service-managed — never stopped by ModelBar
